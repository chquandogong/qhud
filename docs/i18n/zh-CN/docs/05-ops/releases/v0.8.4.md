## 在 Windows 上重新连接账户

在凭据过期的个人或团队行点击**重新登录**。如果独立配置中已登录其他账户，请点击**登录此账户**。Claude 会预填邮箱，如果组织 ID 已知，也会预选组织。Codex 会先尝试使用现有会话。如果需要重新登录且工作区 ID 已知，登录将限定在该工作区。如果浏览器显示其他账户，请切换到该行所示的邮箱。

qhud 在单独的配置目录中核实新登录，再更新现有连接。如果取消或选择了其他邮箱或工作区，原有登录会保留。验证通过后，qhud 会重新查询用量，并显示是否已收到该账户的新数据。

## Claude 限额重置

如果用量响应没有提供剩余数量，qhud 可以显示该成员和组织在**设置 → 用量 → 限额重置**页面最近一次核实的记录。展开标签可查看每类重置券的数量、到期时间及核实时间。过期的重置券会从总数中扣除。供应商返回的数量优先，包括零。

在 Windows 上，请从托盘退出 qhud，解压发行版 ZIP，然后以同一 Windows 账户重新启动。原有账户配置会继续使用。
