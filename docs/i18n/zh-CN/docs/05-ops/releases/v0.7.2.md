qhud v0.7.2 在实时窗格读数不带重置时间时，仍保留配额行的重置倒计时。它也是首个打包
v0.7.1 之后合入 `main` 的安全工作的版本。

- **保留重置倒计时。** 提供方行会合并实时窗格读数与 qhud 保存的用量快照，百分比仍以窗格为准。以前窗格仪表会连同重置时间整体替换快照仪表，因此一个报告每周 0% 却没有重置时间的空闲 Codex 窗格，遮住了上次获取早已得知的倒计时。现在没有重置时间的窗格仪表会采用快照中的重置时间，但从不采用已经过去的重置时间：它属于已结束的窗口，该行不显示倒计时，而不是显示错误的倒计时。
- **依赖补丁。** `quinn-proto` 锁定为 0.11.17，修复旧版远程内存耗尽安全通告。
- **日常诊断脱敏。** Codex、Claude、终端多路复用器、存储及前端的日常日志不再包含账户标签、ID、路径、用量值或异常原文。显式 JSON dump 命令仍是操作者主动请求的诊断，分享前必须脱敏。
- **经过门禁的发布。** 这是首个从受保护的 `main` 经受保护标签流程生成的版本：完整 CI 门禁、带 SHA-256 文件与构建来源证明的四个资产，以及发布前经过审核的草稿。

已在 Ubuntu 24.04 的实际会话中验证：在存在空闲 Codex 窗格以及当天较早一次 Codex 获取结果的情况下，`--dump` 报告的每周行带有该次获取的重置时间；重启后的组件在原先只显示 `0%`、没有倒计时的位置显示 `7D 6% · 6d 20h`。Windows 共用该合并代码，但未在实机上重新验证；其 CI 测试与构建仍是门禁。
