qhud v0.6.2 自动显示本地登录信息中的 Codex 邮箱。此前，即使 Codex ID 令牌已包含邮箱，新电脑没有操作者标签时仍会显示较长的账户/工作区 ID。

- **自动显示邮箱。** 从当前 Codex 主目录中本地 `auth.json` 的 ID 令牌载荷读取邮箱，并遵循 `CODEX_HOME` 设置。通常只要登录信息中有邮箱，就不再需要在每台电脑上配置 `accounts.json` 标签映射。
- **保留现有覆盖设置和账户区分。** 操作者标签优先于邮箱。邮箱/令牌缺失或格式错误时回退到账户 ID。身份和用量归属仍由账户/工作区 ID 决定，邮箱不会合并不同工作区。
- **仅用于本地显示。** 邮箱识别不发起网络请求、不写入凭据，也不执行 OAuth refresh grant。解码后的邮箱只是显示信息，并非经过验证的认证声明。
- **三语文档。** 本版本包含以韩语为默认语言的新版 README、完整英语/韩语/简体中文文档，以及更新后的安装与邮箱显示说明。

两平台测试/构建作业均须通过后才发布。Windows x64 ZIP 和 Linux x86_64 tarball 下载均附 SHA-256 校验和文件。发布归档不包含凭据、账户设置或操作者标签。
