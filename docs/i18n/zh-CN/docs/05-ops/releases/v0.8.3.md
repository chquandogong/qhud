每个价格标签用蓝色条显示一个月均标价。`m` 表示月付，`y` 表示年付，`y` 旁的金额为折合月价。结算周期未知时，仅显示公开月付价。Free 显示 **$0**。每格为 **$200**，因此 **$500** 占 2.5 格。

对于 Codex Business 和 Claude Team，Standard 席位显示 **$25 m** 或 **$20 y**，Premium 显示 **$125 m** 或 **$100 y**。Claude Team 采用 Claude Code 为该账户和组织记录的常规席位类型。**Max 5x** 表示成员的用量等级。席位类型未指定时显示起价，例如 **$25+**。已识别的 Claude 特殊席位没有公开费率时显示**价格未确认**。展开该行可查看定价依据。

韩语界面的 Google AI Pro 在月付时显示 **₩29,000 m**，按年支付 ₩290,000 时显示折合月价 **₩24,167 y**。填充长度采用美国同一结算周期的月均标价，便于跨币种比较。

`accounts.json` 中的结算周期记录包含核实时间，仅用于供应商、邮箱、工作区和套餐均匹配的行。对于供应商仅提供月付的付费套餐，可依据其公开条款显示 `m`。

在 Windows 上，从系统托盘退出 qhud，以发布 ZIP 中的可执行文件替换原文件，再使用同一 Windows 账户启动即可继续使用已有账户配置。
