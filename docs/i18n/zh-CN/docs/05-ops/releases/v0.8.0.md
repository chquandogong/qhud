在 qhud v0.8.0 的用量面板中可以查看账户连接状态、剩余重置次数和各套餐的模型说明。

- Windows 可以连接已安装的 Codex CLI 和正在运行的 Antigravity 应用。Codex、Claude 和 Antigravity 会显示本机是否就绪、可读取的凭据到期时间、上次刷新结果及已保存用量的时间。`qhud --provider-health` 读取本机状态，`qhud --refresh-health` 主动刷新用量。
- 在 `accounts.json` 中可以注册 Codex 和 Claude 的个人与团队配置。`scripts/Connect-Account.ps1` 为独立配置打开供应商的登录流程。等待登录的配置会显示连接状态，配额数值留空。即使两人共用同一个 Codex 工作区，也会分别显示各自登录账户的用量。
- 重置次数显示供应商返回的剩余数量，包括零。Claude 显示个人 Ultra 或 Max 5x，并分别展示团队成员的使用等级和组织套餐。Antigravity 在账户用量快照旁显示原生应用返回的套餐名称，例如 Google AI Pro。
- 在已识别的套餐或席位旁展开**支持模型**，即可查看核对日期为 2026-11-23 的说明，包括付费订阅与试用、团队席位类型和点数计费等条件。供应商的模型选择器反映账户当前的实际权限。手动核实的 Codex 团队席位会注明来源及核实日期。

2026-11-23 在开发中的原生 Windows 小组件中，已实际展开保存的 Standard 席位的模型说明。该 Codex 配置仍需登录，尚未验证其实时配额获取。
