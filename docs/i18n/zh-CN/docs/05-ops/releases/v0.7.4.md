qhud v0.7.4 修复窄系统条中的重叠问题，并推进依赖栈。

- **窄系统条。** 窄窗口中磁盘速率会画到网络标签上：WebKitGTK 渲染系统条中的小号等宽文字比浏览器更大，导致半行宽的速率单元格溢出。现在 CSS 宽度低于 320 像素时每个速率独占一行，仍放不下的数值在自身单元格内裁剪。更宽的窗口保持共用一行。
- **Tauri 2.12.1。** Tauri 从 2.11 升级到 2.12.1，并同步更新 tauri-build 2.7.1 及 window-state、opener、single-instance 插件。`sysinfo` 更新至 0.38.4。Tauri 2.12 移除了 `urlpattern` 0.3，因此依赖策略中删除了五个无人维护 crate 的例外。
- **源码构建需 Rust 1.90。** 声明的最低版本从 1.88 提高到 Tauri 2.12 所需的 1.90。锁定的依赖图此前已需要 1.89，因此 1.88 已不准确；新的 CI 作业现在使用所声明的版本构建。
- **仓库。** `Rust dependency policy` 现在是 `main` 的必需检查；README 改为展示演示模式下的原生 Linux 画面（紧凑、展开与 About），而非浏览器渲染。

已在 Ubuntu 24.04 上以演示模式在 Xvfb 中运行原生 release 构建进行验证：系统条在 300、360、450 和 600 像素宽的窗口中检查，主窗口、托盘、展开的卡片和 About 对话框均已渲染，画面持续重绘。Tauri 2.12 构建在发布前未在实际 GNOME 会话或 Windows 实机上运行；Windows CI 的测试与构建仍是门禁。
