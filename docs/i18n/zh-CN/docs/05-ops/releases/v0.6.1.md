qhud v0.6.1 是文档与验证版本。二进制行为与 v0.6.0 完全一致，源码只改动过时注释，因此已运行 v0.6.0 的用户可选择是否升级。

- **从头重写规格。** `docs/03-spec/SPEC.md` 和 `docs/03-spec/ARCHITECTURE.md` 根据 v0.6.0 源码重建，而非局部修补。旧 SPEC 停留在 v0.5.0，旧 ARCHITECTURE 是 v0.4.0 文档，两者遗漏了四个模块、双平台路径处理、帧守卫、双平台发布，以及此后新增的所有 CLI 标志和环境变量。需求现覆盖每个已发布版本，并附带产生它的决策。
- **记录 Ubuntu 验证。** v0.6.0 从 Windows 主机发布，注明尚未重新验证 Ubuntu 桌面集成。现在已对公开的 v0.6.0 Linux 产物完成：校验和验证、安装，并在参考机器确认桌面层窗口状态、像素活性、多路复用器观测及三个供应商刷新。带日期证据位于 `docs/04-quality/TEST_PLAN.md` 和 `docs/00-overview/DASHBOARD.md`。
- **更新风险与假设。** 风险登记现包含现场事件中占主导的显示器睡眠帧冻结、供应商传输格式漂移和 Windows 特有限制；修正过时的单平台及“从不持久化”假设。
- **修正现场数字。** 帧守卫 journal 统计为 28 次冻结、28 次重新映射恢复、零重新执行、零操作者可见事故（2026-08-26 → 09-07）。先前发布引用的较小数字来自守卫最初几天。

发布不包含凭据、账户设置或操作者显示名称。两平台构建和测试作业必须通过后才发布，两份下载均附 SHA-256 校验和文件。
