qhud v0.8.1 在各供应商下按邮箱归集用量。每个邮箱下先列个人，再列各团队，方便对照套餐、各时段用量和重置时间。等待连接的档案也列在对应的邮箱下。

如果 Claude 个人档案已在网页确认为 **Free**，且没有返回配额，便会显示**不提供用量**，并隐藏仪表。套餐详情中可查看核实时间。收到与该个人账户匹配的用量后，会优先显示该读数。同一邮箱的团队用量仍列在团队行。

2026-11-23 在 Windows 本地构建中确认，Codex 个人行和团队行可以同时显示。Claude 在同一邮箱下为 Free 个人行显示**不提供用量**，同时显示付费团队的用量。在 Windows 上更新时，请从托盘退出 qhud，使用发行版 ZIP 中的可执行文件替换原文件，再使用同一 Windows 账户重新打开。
