qhud v0.8.2 在已识别的套餐名称旁显示美国月度标价。更醒目的填充色以 $200 为一格，$100 填充半格，$500 填充 2.5 格。Free 显示 $0，填充为空。5H 和 7D 用量条显示各周期已用额度的百分比。

工作区已确认为 Codex Business 或 Claude Team、席位类型未知时，显示每席每月 **$20–125**。此范围包括 Standard 与 Premium 席位的年付月均价和月付标价。若 Codex 席位已核实，Standard 显示 **$20–25**，Premium 显示 **$100–125**。Claude 团队的 **Max 5x** 是成员用量等级，可与团队价格范围同时显示。展开该行可查看计价依据。标价核对日期为 **2026-11-24**，实际收费以账单为准。

2026-11-24 在 Windows 本地构建中确认，个人、团队和 Free 账户行均能显示价格标签。在另一次浏览器测试中，使用模拟账户在 361px 和 394px 窗口宽度下测量，两种宽度下 $200 均为 64px，$500 均为 160px。

Windows 用户可从托盘退出 qhud，用发布版 ZIP 中的可执行文件替换旧文件，再以同一 Windows 账户启动，即可继续使用现有账户档案。
