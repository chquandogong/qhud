qhud v0.6.0 新增原生 Windows x64 小组件，同时保留 Linux x86_64 发布。

- **Windows：** 解压 `qhud-v0.6.0-windows-x86_64.zip` 后运行 `qhud.exe`。需要 Microsoft Edge WebView2 Runtime。账户用量无需 WSL 即可使用；尚未实现原生 Windows Terminal/PowerShell 窗格发现。
- **Linux：** 照常安装 `qhud-v0.6.0-linux-x86_64.tar.gz` 二进制。GTK/X11 和 tmux/herdr 代码路径保留；源码构建继续使用固定 Git 依赖，无需本地依赖检出目录。
- **模型限额：** 保留仅模型读数及每个窗口的重置，处理可为 null 的 Codex 限额映射，并修复当前 Codex app-server 回退。长模型名称换行，用量区可滚动，悬停仪表可看准确重置时间。只有供应商返回模型限额时才显示。
- **账户正确性：** 保存用量与当前登录账户匹配，防止同时进行的供应商刷新互相覆盖。

升级说明：没有多路复用器时，qhud 现在显示真实本地账户快照和零窗格；示例数据使用 `--demo`。遵循供应商/配置主目录环境变量覆盖。缺少账户身份的旧 Antigravity 快照须显式刷新一次。发布不包含凭据或用户账户设置。

验证：Ubuntu 24.04 通过 fmt/clippy、98 项测试和 release 构建；Windows 通过 98 项测试和 release 构建。已安装 Windows 二进制也通过显示和账户刷新冒烟检查。此次 Windows 移植期间没有重新手工测试 Ubuntu 桌面集成。

两平台构建/测试作业均通过后才发布本版本。下载附带 SHA-256 校验和文件。
