<a id="support"></a>

# 支持

qhud 是由社区维护的项目。我们会尽力以 English、한국어 和简体中文提供帮助。

<a id="before-asking"></a>

## 提问之前

请先查看[用户指南](docs/GUIDE.md)、[运维手册](docs/05-ops/RUNBOOK.md)中的平台说明和[已有 issue](https://github.com/chquandogong/qhud/issues)。请尽量使用最新版本；报告版本时，请填写准确的版本号（例如 `vX.Y.Z`）或 commit SHA。

<a id="choose-the-right-channel"></a>

## 选择合适的渠道

- 可复现的 qhud 故障请使用[缺陷报告表单](https://github.com/chquandogong/qhud/issues/new?template=bug_report.yml)。
- 新行为或使用场景请使用[功能建议表单](https://github.com/chquandogong/qhud/issues/new?template=feature_request.yml)。
- 安装、配置或文档行为不清楚时，请使用[支持问题表单](https://github.com/chquandogong/qhud/issues/new?template=support_question.yml)。
- 疑似漏洞请按照 [SECURITY.md](SECURITY.md) 私下报告。
- 服务商账户访问、订阅、计费、服务状态或服务商端身份验证故障，请联系相应 AI 服务商。

请提供操作系统和桌面环境、安装方式、qhud 版本、服务商或组件、已尝试的操作及准确结果。维护者可能会先请您确认问题能否在最新版本上复现，再调查旧版本。

<a id="protect-private-data"></a>

## 保护私密数据

诊断信息和截图可能包含邮箱地址、账户或组织 ID、本地路径、会话内容、token 和凭据。发布前请检查并脱敏。切勿附上 `auth.json`、`.credentials.json`、服务商配置目录或未经检查的完整诊断包。请尽量使用小型合成示例。
