<a id="community-conduct"></a>

# 社区行为准则

qhud 欢迎通过代码、文档、测试、提问和认真批评做出贡献的人。我们希望项目空间对不同语言、经验水平、身份和能力的人都实用且安全。

<a id="how-we-work-together"></a>

## 我们如何协作

- 围绕工作、证据和影响展开讨论。可以质疑观点，但不要攻击提出观点的人。
- 当语言或技术背景不同时，请清晰、耐心地沟通。纠正错误时不要羞辱他人，也请接受善意的纠正。
- 反馈应与主题相关，并给其他人留出参与空间。
- 保护私密信息。请对日志和截图脱敏，绝不泄露凭据或他人的身份与账户数据。

我们不接受骚扰、歧视、威胁、跟踪、性暗示关注、蓄意恐吓、人肉搜索、泄露凭据、持续扰乱或垃圾信息。

<a id="scope-and-enforcement"></a>

## 适用范围与处理

本政策适用于仓库 issue、pull request、review、release，以及任何代表 qhud 项目的其他空间。

对于一般问题，请在原对话中要求更正，不要重复有害或私密内容。私密或紧急报告请使用 GitHub 的屏蔽与滥用举报工具。请勿在公开 issue 中披露敏感个人信息。

维护者可根据行为的严重程度和重复情况编辑或删除内容、发出警告、限制参与或封禁账户。报告只会与调查所需人员共享。如有其他审核者，与报告有关的维护者应回避处理决定。
