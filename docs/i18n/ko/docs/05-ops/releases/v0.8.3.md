가격 칩에는 월 기준 정가 하나와 파란 막대가 표시됩니다. `m`은 월 결제, `y`는 연 결제이며 `y` 옆 금액은 월 환산액입니다. 결제 주기를 모르면 월 결제 정가만 표시합니다. Free는 **$0**입니다. 한 칸은 **$200**이므로 **$500**은 2.5칸입니다.

Codex Business와 Claude Team의 Standard 좌석은 **$25 m** 또는 **$20 y**, Premium은 **$125 m** 또는 **$100 y**로 표시됩니다. Claude Team은 Claude Code가 해당 계정과 조직에 기록한 일반 좌석 유형을 사용합니다. **Max 5x**는 구성원의 사용 등급입니다. 좌석 종류가 지정되지 않았으면 **$25+**처럼 시작 가격을 표시합니다. 특수 Claude 좌석으로 확인됐으나 공개 정가가 없으면 **가격 미확인**으로 표시합니다. 행을 펼치면 가격의 근거를 확인할 수 있습니다.

한국어 화면의 Google AI Pro는 월 결제 시 **₩29,000 m**, 연 ₩290,000 결제 시 월 환산액 **₩24,167 y**로 표시됩니다. 막대 길이는 같은 결제 주기의 미국 월 환산 정가를 사용하므로 통화가 달라도 비교할 수 있습니다.

`accounts.json`의 결제 주기 기록은 확인 시각을 포함하며 공급자, 이메일, 워크스페이스, 요금제가 일치하는 행에만 적용됩니다. 공식적으로 월 결제만 제공하는 유료 요금제는 공급자 요금표에 따라 `m`을 표시할 수 있습니다.

Windows에서는 트레이에서 qhud를 종료하고 릴리스 ZIP의 실행 파일로 교체한 뒤 같은 Windows 계정으로 실행하세요. 기존 계정 프로필을 계속 사용할 수 있습니다.
