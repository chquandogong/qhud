qhud v0.7.3은 Codex 요금제 배지에 현재 제품 이름을 표시하고, v0.7.2 이후 완료한
보안·의존성·릴리스·번역 작업을 패키지에 담습니다.

- **현재 Codex 요금제 이름.** 검토된 wire 값 `prolite`, `pro`, `promax`를 각각
  **Pro 100**, **Pro 200**, **Pro 500**으로 표시합니다. 이 매핑은 Codex upstream의
  [wire enum](https://github.com/openai/codex/blob/f70810bcd210ed780a3da5940e9e60f74ac8ee60/codex-rs/protocol/src/auth.rs#L73-L95),
  [구독 레이블](https://github.com/openai/codex/blob/f70810bcd210ed780a3da5940e9e60f74ac8ee60/codex-rs/tui/src/subscription.rs#L10-L19),
  [회귀 사례](https://github.com/openai/codex/blob/f70810bcd210ed780a3da5940e9e60f74ac8ee60/codex-rs/tui/src/status/helpers.rs#L200-L221)를 따릅니다.
  `accounts.json`에 명시한 요금제 레이블은 계속 가장 우선하는 표시 override입니다.
  알 수 없는 공급자 값은 상세 텍스트에는 남지만 사용자에게 보이는 배지가 되지 않습니다.
- **보안 게이트와 비식별 오류.** cargo-deny 작업이 고정된 Rust 그래프의 권고,
  라이선스, 출처를 검사합니다. 그래프에는 RUSTSEC-2026-0285를 해결한 rustls 0.23.45가
  포함됩니다. 남은 평상시 라이브러리 실패는 URL, 경로, 터미널 멀티플렉서 출력을 담을 수
  있는 upstream 원문을 복사하지 않고 제한된 형식화 범주를 사용합니다.
- **검증된 릴리스 자산.** 릴리스에 CycloneDX 1.5 JSON SBOM, SHA-256 파일, 출처 증명을
  포함합니다. 게시 작업은 릴리스 목록에서 초안을 안정적으로 이어받고 자산이 정확히 6개인지
  확인하며, 내용이 다르거나 예상하지 않은 파일을 거부합니다. `codex/**` 작업은 브랜치 push와
  PR에서 각각 실행하지 않고 PR을 통해 한 번만 CI를 실행합니다.
- **의존성과 번역.** base64 0.23, libloading 0.9, reqwest 0.13.5, toml 1.1.6을
  포함합니다. 저장소는 완전한 한국어·중국어 간체 미러가 필요한 영어 문서를 명시하고,
  CI에서 사실과 변경 범위를 검사합니다.

자동 JavaScript 회귀 테스트는 세 가지 정확한 요금제 매핑, 대소문자와 앞뒤 공백 정규화,
명시적 override 우선순위, 알 수 없는 wire 값 숨김을 다룹니다. 이 노트를 준비하기 전에
새로운 실제 데스크톱 요금제 배지 검증은 수행하지 않았습니다. 날짜가 기록된 v0.7.2 실행
근거가 최신 실제 실행 근거로 유지됩니다.
