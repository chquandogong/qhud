qhud v0.7.2는 실시간 패인 값에 리셋 시각이 없어도 할당량 행의 리셋 카운트다운을
유지합니다. 또한 v0.7.1 이후 `main`에 반영된 보안 작업을 처음으로 패키지에 담은
릴리스입니다.

- **리셋 카운트다운 유지.** 제공자 행은 실시간 패인 값과 qhud가 저장한 사용량
  스냅숏을 합치며, 백분율은 계속 패인 값이 우선합니다. 이전에는 패인 게이지가 리셋
  시각까지 포함해 스냅숏 게이지를 통째로 대체했기 때문에, 주간 0%를 리셋 시각 없이
  보고하던 유휴 Codex 패인이 마지막 조회가 이미 알던 카운트다운을 가렸습니다. 이제
  리셋 시각이 없는 패인 게이지는 스냅숏의 리셋 시각을 가져옵니다. 다만 이미 지나간
  리셋 시각은 끝난 구간의 것이므로 가져오지 않으며, 잘못된 카운트다운 대신 카운트다운을
  표시하지 않습니다.
- **의존성 패치.** `quinn-proto`를 0.11.17로 고정해 이전 리비전의 원격 메모리 소진
  권고 사항을 해결했습니다.
- **평상시 진단 로그 비식별화.** Codex, Claude, 터미널 멀티플렉서, 저장소, 프런트엔드의
  평상시 로그에 계정 레이블, ID, 경로, 사용량 값, 예외 원문이 더 이상 남지 않습니다.
  명시적 JSON dump 명령은 운영자가 요청하는 진단 기능으로 유지하며, 공유 전에 가려야
  합니다.
- **게이트를 거친 게시.** 보호된 `main`에서 보호된 태그 워크플로로 만든 첫 릴리스입니다.
  전체 CI 검증, SHA-256 파일과 빌드 출처 증명을 갖춘 네 개의 자산, 검토를 거친 초안을
  모두 통과해야 게시됩니다.

Ubuntu 24.04 실제 세션에서 검증했습니다. 유휴 Codex 패인과 같은 날 앞서 받은 Codex
조회 결과가 있는 상태에서 `--dump`가 조회 결과의 리셋 시각을 담은 주간 행을 보고했고,
재시작한 위젯은 카운트다운 없이 `0%`만 보이던 자리에 `7D 6% · 6d 20h`를 표시했습니다.
Windows는 같은 병합 코드를 쓰지만 실제 기기에서 다시 검증하지 않았으며, Windows CI의
테스트와 빌드가 계속 게이트입니다.
