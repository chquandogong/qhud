qhud v0.8.2에서는 요금제 옆 칩에서 미국 월 정가를 확인할 수 있습니다. 선명한 색으로 $200당 한 칸을 채웁니다. $100은 반 칸, $500은 2.5칸이고, Free는 채움 없이 $0입니다. 5H·7D 막대는 각 기간의 한도 대비 사용률을 나타냅니다.

Codex Business 또는 Claude Team 요금제가 확인되면 좌석 유형이 없어도 **$20–125**를 표시합니다. Standard와 Premium의 연 결제 월 환산액부터 월 결제 가격까지 포함한 좌석당 범위입니다. Codex에서 좌석까지 확인되면 Standard는 **$20–25**, Premium은 **$100–125**로 좁혀집니다. Claude 팀의 **Max 5x**는 구성원 사용 등급이므로 팀 가격 범위와 함께 표시할 수 있습니다. 행을 펼치면 가격 기준을 볼 수 있습니다. 정가 확인일은 **2026-11-24**이며, 실제 결제액은 청구서에서 확인하세요.

2026-11-24에 Windows 로컬 빌드에서 개인·팀·Free 계정 행의 가격 칩을 확인했습니다. 별도의 브라우저 검사에서 가상 계정을 사용해 창 너비 361px와 394px에서 측정한 결과, 두 경우 모두 $200은 64px, $500은 160px였습니다.

Windows에서는 트레이에서 qhud를 종료하고 릴리스 ZIP의 실행 파일로 교체한 뒤 같은 Windows 계정에서 다시 실행하면 기존 계정 프로필을 계속 사용할 수 있습니다.
