qhud v0.7.0은 기존 계정·세션 화면 아래에 작은 시스템 사용량 그래프와
실행 중인 빌드를 확인하는 About 패널을 추가합니다.

- **작고 읽기 쉬운 기록.** CPU, MEM, 지원되는 GPU, DISK, NET을 2초마다 갱신하고
  최근 약 1분의 최대 30개 표본을 보관합니다. 항목을 선택하면 상세가 열리고
  다시 선택하면 닫힙니다. Tab + Enter/Space로도 조작합니다.
  백분율 그래프는 0–100% 고정 축, 속도 그래프는 최근 읽기·쓰기 또는 수신·송신에
  맞춘 축을 사용합니다.
- **명확한 측정 범위.** 디스크 속도는 파티션이나 중첩 장치 입출력을 중복 합산하지
  않은 물리 장치 전체 값입니다. 용량 상세는 중복을 제거한 로컬 볼륨이며 30초마다
  갱신합니다. 네트워크는 사용 가능한 IP가 있는 비루프백 인터페이스를 합산하고
  Linux는 내려간 인터페이스도 제외합니다. VPN·가상·물리 인터페이스에서는 같은
  트래픽이 중복 집계될 수 있습니다.
- **측정 가능한 GPU.** Windows는 WDDM GPU Engine 카운터에서 어댑터별 가장 바쁜
  엔진을 사용합니다. Linux는 AMD의 사용 가능한 sysfs busy 카운터와 설치된 NVML을
  통한 NVIDIA를 지원합니다. 최초 유효 표본에서 선택한 어댑터 하나를 측정 세션
  동안 유지합니다. Linux VRAM 상세는 측정원이 제공할 때만 표시하며 Windows
  VRAM과 다른 미지원 GPU 측정원은 측정 불가로 남깁니다.
- **조용한 측정.** 숨김·최소화 중에는 시스템 측정을 중지합니다. 창을 다시 표시하면
  기록을 새로 시작하고 속도 기준값을 준비합니다. 카운터 없음·첫 속도 표본·초기화는
  빈 구간/`--`로, 정상 유휴 상태는 0으로 표시합니다. 데이터는 메모리에만 보관하고
  외부로 전송하지 않습니다. 시스템 수집은 프로세스 스캔이나 모니터링 명령 실행 없이
  로컬 API를 사용합니다.
- **정보와 진단.** 왼쪽 위 **qhud**를 클릭하면 내장 버전, 제작자
  **Chenghao Quan (chquandogong)**,
  [홈페이지](https://chquandogong.github.io/CHENGHAO-QUAN/)와 저장소를 확인합니다.
  `qhud --system-dump`는 계정 정보를 읽거나 위젯을 열지 않고 두 로컬 표본을
  측정하여 JSON으로 출력합니다. 명시적 데모 모드는 합성 시스템 데이터를 사용합니다.

GPU 칸이 없다는 것은 지원되는 표본을 얻지 못했다는 뜻이며 컴퓨터에 GPU가 없다는
증거는 아닙니다. 지원되는 GPU가 일시 실패하면 칸을 유지하고 빈 구간을 표시합니다.
시스템 지표는 에이전트별 자원 비용이 아닌 컴퓨터 전체 값입니다.

Windows와 Ubuntu의 테스트·빌드 통과를 배포 조건으로 유지합니다.
Windows x64 ZIP과 Linux x86_64 tarball에는 SHA-256 파일이 함께 제공됩니다.
기존 계정 설정은 포터블 아카이브 밖에 유지됩니다.
