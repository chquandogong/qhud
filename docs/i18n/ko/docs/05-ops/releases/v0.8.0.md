qhud v0.8.0의 사용량 패널에서 계정 연결 상태, 남은 초기화권, 요금제별 지원 모델을 확인할 수 있습니다.

- Windows에서 설치된 Codex CLI 및 실행 중인 Antigravity 앱에 연결합니다. Codex·Claude·Antigravity에서 조회 준비 상태, 확인 가능한 인증 만료 시각, 마지막 조회 결과와 저장된 사용량의 경과 시간을 볼 수 있습니다. `qhud --provider-health`는 로컬 상태를 읽고 `qhud --refresh-health`는 사용량을 새로 조회합니다.
- `accounts.json`에 Codex·Claude의 개인·팀 프로필을 등록할 수 있습니다. `scripts/Connect-Account.ps1`는 별도 프로필에서 공급자의 로그인 절차를 엽니다. 로그인 대기 중인 프로필에는 사용량 수치 없이 연결 상태가 표시됩니다. 두 사람이 같은 Codex 워크스페이스를 사용해도 각각의 로그인에 속한 사용량을 구분합니다.
- 초기화권에는 0을 포함해 공급자가 반환한 남은 개수가 표시됩니다. Claude는 개인 Ultra·Max 5x와 팀 구성원의 사용 등급을 표시하며, 팀의 조직 요금제도 따로 확인할 수 있습니다. Antigravity는 Google AI Pro 등 앱이 반환한 요금제 이름을 해당 계정의 저장된 사용량과 함께 표시합니다.
- 확인된 요금제나 좌석 옆 **지원 모델**을 누르면 2026-11-23 기준 안내가 펼쳐집니다. 유료 구독·체험판, 팀 좌석 유형, 크레딧 과금 등 모델 이용 조건을 볼 수 있습니다. 현재 계정의 실제 권한은 공급자 앱의 모델 선택기에서 확인할 수 있습니다. 수동으로 확인한 Codex 팀 좌석에는 출처와 확인 날짜가 표시됩니다.

개발 중인 Windows 위젯에서 2026-11-23에 저장된 Standard 좌석의 모델 안내를 직접 펼쳐 확인했습니다. 해당 Codex 프로필은 로그인이 필요한 상태여서 실시간 사용량 조회는 검증하지 못했습니다.

이번 빌드에는 Rustls, WebPKI, Tokio, rustix와 URL 파서 보안 업데이트가 포함됩니다. 고정된 qmonster가 기존 SQLite API를 계속 사용할 수 있도록 어댑터를 통해 rusqlite 0.41.1과 libsqlite3-sys 0.39.1을 연결했습니다. CI 액션의 고정 버전과 Tauri 패치 버전도 갱신했습니다.
