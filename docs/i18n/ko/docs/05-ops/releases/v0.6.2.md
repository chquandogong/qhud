qhud v0.6.2는 로컬 로그인 정보에 있는 Codex 이메일을 자동으로 표시합니다. 이전에는 Codex ID 토큰에 이메일이 있어도 새 컴퓨터에 운영자 레이블이 없으면 긴 계정/작업 공간 ID를 표시했습니다.

- **이메일 자동 표시.** 현재 Codex 홈의 로컬 `auth.json` ID 토큰 페이로드에서 이메일을 읽으며 `CODEX_HOME` 설정을 따릅니다. 일반적인 이메일 포함 로그인에서는 컴퓨터마다 `accounts.json` 레이블 매핑을 만들 필요가 없습니다.
- **기존 표시 재정의와 계정 구분 유지.** 운영자 레이블은 이메일보다 우선합니다. 이메일/토큰이 없거나 형식이 잘못되면 계정 ID를 표시합니다. 식별과 사용량 소유권은 계속 계정/작업 공간 ID로 판단하며 이메일 때문에 서로 다른 작업 공간을 합치지 않습니다.
- **로컬 표시 전용.** 이메일 인식은 네트워크 요청, 자격 증명 쓰기, OAuth refresh grant를 수행하지 않습니다. 디코딩한 이메일은 표시용 보조 정보이며 검증된 인증 정보가 아닙니다.
- **세 언어 문서.** 한국어 기본 README 개편, 전체 영어·한국어·중국어 간체 문서, 갱신된 설치 및 이메일 표시 안내를 포함합니다.

공개 전에 두 플랫폼의 테스트/빌드 작업이 모두 통과해야 합니다. Windows x64 ZIP과 Linux x86_64 tarball에는 SHA-256 체크섬 파일을 제공합니다. 릴리스 아카이브에는 자격 증명, 계정 설정, 운영자 레이블을 포함하지 않습니다.
