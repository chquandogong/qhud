qhud v0.8.1에서는 공급자별 사용량을 이메일로 묶어 보여줍니다. 각 이메일 아래에 개인 행이 먼저, 팀 행이 그다음에 표시되어 요금제와 기간별 사용량, 초기화 시각을 비교할 수 있습니다. 연결을 기다리는 프로필도 같은 이메일 아래에 표시됩니다.

Claude 웹에서 **Free**로 확인한 개인 프로필에 한도 정보가 없으면 게이지 없이 **사용량 미제공**으로 표시합니다. 요금제 상세에서 확인 시각을 볼 수 있습니다. 해당 개인 계정의 사용량을 받아오면 그 값이 우선하며, 같은 이메일의 팀 사용량은 팀 행에서 확인할 수 있습니다.

2026-11-23에 Windows 로컬 빌드에서 Codex 개인·팀 행이 함께 표시되는 것을 확인했습니다. Claude에서는 같은 이메일의 개인 Free에 **사용량 미제공**이, 유료 팀에는 사용량이 표시됐습니다. Windows에서 업데이트하려면 트레이에서 qhud를 종료하고 릴리스 ZIP의 실행 파일로 교체한 뒤 같은 Windows 계정에서 다시 실행하세요.
