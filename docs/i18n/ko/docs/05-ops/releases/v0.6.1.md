qhud v0.6.1은 문서 및 검증 릴리스입니다. 소스 수정은 오래된 주석뿐이므로 바이너리 동작은 v0.6.0과 정확히 같습니다. 이미 v0.6.0을 실행 중이면 업그레이드는 선택 사항입니다.

- **사양을 전면 개정했습니다.** `docs/03-spec/SPEC.md`와 `docs/03-spec/ARCHITECTURE.md`를 부분 수정하는 대신 v0.6.0 소스를 기준으로 다시 작성했습니다. 이전 SPEC은 v0.5.0에서 멈췄고 ARCHITECTURE는 v0.4.0 문서였습니다. 두 문서에는 모듈 네 개, 두 플랫폼의 경로 처리, 프레임 가드, 두 플랫폼 릴리스, 그 이후 추가된 CLI 플래그와 환경 변수가 빠져 있었습니다. 이제 모든 출시 버전의 요구 사항과 각 요구를 만든 결정을 담습니다.
- **Ubuntu 검증을 기록했습니다.** v0.6.0은 Windows 호스트에서 출시되어 Ubuntu 데스크톱 통합을 재검증하지 않았다고 명시했습니다. 이제 공개 v0.6.0 Linux 배포 파일로 체크섬 검증과 설치를 마쳤고 기준 장비에서 데스크톱 계층 창 상태, 실제 픽셀 갱신, 멀티플렉서 관찰, 세 공급자 새로고침까지 확인했습니다. 날짜별 근거는 `docs/04-quality/TEST_PLAN.md`와 `docs/00-overview/DASHBOARD.md`에 있습니다.
- **위험과 가정을 갱신했습니다.** 등록부는 현장 사건의 대부분을 차지하는 디스플레이 절전 프레임 정지, 공급자 응답 형식 변경, Windows 전용 제한을 포함합니다. 오래된 단일 플랫폼 및 아무것도 저장하지 않는다는 가정을 수정했습니다.
- **현장 수치를 바로잡았습니다.** 프레임 가드의 journal 집계는 2026-08-26 → 09-07에 정지 28회, remap 복구 28회, 재실행 0회, 사용자에게 드러난 사고 0회입니다. 이전 릴리스는 가드 운영 초기의 훨씬 작은 수치를 인용했습니다.

릴리스에는 자격 증명, 계정 설정, 운영자의 표시 이름을 포함하지 않습니다. 공개 전에 두 플랫폼의 빌드와 테스트 작업이 모두 통과해야 하며 두 다운로드에 SHA-256 체크섬 파일을 제공합니다.
