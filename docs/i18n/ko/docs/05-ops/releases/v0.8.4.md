## Windows에서 계정 다시 연결하기

인증이 만료된 개인·팀 행에서 **다시 로그인**을 누르세요. 격리된 프로필에 다른 계정이 연결돼 있으면 **이 계정으로 로그인**을 누르세요. Claude는 이메일을 미리 입력하고, 조직 ID를 알고 있으면 해당 조직도 미리 선택합니다. Codex는 기존 세션으로 먼저 갱신을 시도하며, 새 로그인이 필요하고 작업공간 ID가 확인돼 있으면 해당 작업공간으로 제한합니다. 브라우저에 다른 계정이 보이면 행에 표시된 이메일로 전환하세요.

qhud는 별도 프로필에서 새 로그인을 확인한 뒤 기존 연결을 갱신합니다. 취소하거나 다른 이메일·작업공간을 선택하면 기존 로그인은 유지됩니다. 인증을 확인하면 사용량을 다시 요청하고, 선택한 계정에서 새 값을 받았는지 표시합니다.

## Claude 제한 초기화

사용량 응답에 초기화권 수가 없으면 같은 계정과 조직의 **설정 → 사용량 → 제한 초기화** 화면에서 마지막으로 확인한 기록을 표시할 수 있습니다. 배지를 펼치면 종류별 개수와 만료 시각, 확인 시각을 볼 수 있습니다. 만료된 초기화권은 합계에서 빠집니다. 공급자가 개수를 반환하면 0개를 포함해 그 값을 우선합니다.

Windows에서는 트레이에서 qhud를 종료하고 배포 ZIP의 압축을 푼 뒤 같은 Windows 계정으로 다시 실행하세요. 기존 계정 설정을 그대로 사용합니다.
