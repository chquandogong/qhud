qhud v0.6.0은 Linux x86_64 릴리스를 유지하면서 Windows x64 네이티브 위젯을 추가합니다.

- **Windows:** `qhud-v0.6.0-windows-x86_64.zip`을 풀고 `qhud.exe`를 실행합니다. Microsoft Edge WebView2 Runtime이 필요합니다. WSL 없이 계정 사용량을 표시하며 Windows Terminal/PowerShell 창의 네이티브 탐색은 구현하지 않았습니다.
- **Linux:** 이전과 같이 `qhud-v0.6.0-linux-x86_64.tar.gz` 바이너리를 설치합니다. GTK/X11 및 tmux/herdr 코드 경로를 유지하며 소스 빌드는 로컬 의존성 checkout 없이 고정 Git 의존성을 계속 사용합니다.
- **모델 한도:** 모델별 수치만 있는 결과와 각 기간의 초기화 시각을 보존하고 null Codex 한도 맵을 처리하며 현재 Codex app-server 대체 경로를 수정했습니다. 긴 모델명은 줄바꿈하고 사용량 영역은 스크롤됩니다. 계기에 마우스를 올리면 정확한 초기화 시각을 볼 수 있습니다. 공급자가 한도를 반환할 때만 모델을 표시합니다.
- **계정 정확성:** 저장 사용량을 로그인 계정과 일치시키고 동시 공급자 새로고침이 서로의 결과를 덮어쓰지 않게 합니다.

업그레이드 안내: 멀티플렉서가 없으면 이제 실제 로컬 계정 스냅샷과 창 0개를 표시합니다. 예시 데이터에는 `--demo`를 사용하세요. 공급자/설정 홈 환경 변수 재정의를 따릅니다. 계정 정보 없는 오래된 Antigravity 스냅샷에는 한 번의 명시적 새로고침이 필요합니다. 릴리스에 자격 증명이나 사용자 계정 설정을 포함하지 않습니다.

검증: Ubuntu 24.04가 fmt/clippy, 테스트 98개, 릴리스 빌드를 통과했고 Windows도 테스트 98개와 릴리스 빌드를 통과했습니다. 설치한 Windows 바이너리는 화면 표시 및 계정 새로고침 스모크 테스트도 통과했습니다. 이번 Windows 이식 과정에서는 Ubuntu 데스크톱 통합을 수동 재검증하지 않았습니다.

릴리스 공개 전에 두 플랫폼의 빌드/테스트 작업이 모두 통과해야 합니다. 다운로드에 SHA-256 체크섬 파일을 제공합니다.
