qhud v0.7.4는 좁은 시스템 표시줄의 겹침을 고치고 의존성 스택을 갱신합니다.

- **좁은 시스템 표시줄.** 좁은 창에서 디스크 속도가 네트워크 레이블 위에 겹쳐 그려졌습니다.
  WebKitGTK는 표시줄의 작은 고정폭 글자를 브라우저보다 크게 렌더링하므로 반 줄짜리 속도
  칸이 넘쳤습니다. 이제 CSS 폭 320픽셀 미만에서는 각 속도가 한 줄을 차지하고, 그래도
  들어가지 않는 값은 자기 칸 안에서 잘립니다. 더 넓은 창은 기존처럼 한 줄을 나눠 씁니다.
- **Tauri 2.12.1.** Tauri를 2.11에서 2.12.1로 올리고 tauri-build 2.7.1과 window-state,
  opener, single-instance 플러그인을 함께 갱신했습니다. `sysinfo`는 0.38.4로 올렸습니다.
  Tauri 2.12가 `urlpattern` 0.3을 제거하므로 유지보수 중단 크레이트 예외 다섯 개가
  의존성 정책에서 빠졌습니다.
- **소스 빌드에 Rust 1.90.** 선언된 최소 버전을 Tauri 2.12가 요구하는 1.90으로 올렸습니다(이전 1.88).
  고정된 의존성 그래프는 이미 1.89를 요구했으므로 1.88은 정확하지 않았으며, 이제 새 CI
  작업이 선언된 버전으로 빌드합니다.
- **저장소.** `Rust dependency policy`가 `main`의 필수 검사가 되었고, README는 브라우저
  렌더링 대신 데모 모드의 네이티브 Linux 화면(간결, 펼침, About)을 보여 줍니다.

Ubuntu 24.04에서 네이티브 릴리스 빌드를 Xvfb의 데모 모드로 실행해 검증했습니다. 표시줄은
300, 360, 450, 600픽셀 창에서 확인했고, 메인 창, 트레이, 펼친 타일, About 대화상자가
렌더링되었으며 화면이 계속 다시 그려졌습니다. Tauri 2.12 빌드는 게시 전에 실제 GNOME
세션이나 Windows 실기에서 실행하지 않았으며, Windows CI의 테스트와 빌드가 계속 게이트입니다.

게시 후인 2026-10-02에 공개된 Windows ZIP의 SHA-256이
`d1c5bcbd7177075fcf00d48cd1d9a2239f8415f97b3ec945eaeeaa59a3a098cf`와
일치했고, 실행 파일과 About 대화상자는 v0.7.4를 보고했습니다. 네이티브 WebView2 빌드는
합성 값, 새로 만든 격리된 공급자·설정 홈, 새로운 100% 확대 비율 프로필을 사용해
격리된 `--demo` 모드로 실행했습니다. 기본 확대 비율에서 CPU/MEM/GPU/DISK/NET 표시줄은 확인한
일반 394픽셀 및 좁은 361픽셀 창 너비에서 겹치지 않았습니다. Windows Graphics Capture로
394×522 크기의 간결, 펼침, About 이미지를 보관했으며 About은 홈페이지와 GitHub 링크를
표시했습니다. 실제 계정은 사용하지 않았고, 이 검증에서는 링크 실행과 나머지 Windows
상호작용 체크리스트를 수행하지 않았습니다.
