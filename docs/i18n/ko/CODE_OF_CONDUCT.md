# 커뮤니티 행동 원칙

qhud는 코드, 문서, 테스트, 질문과 세심한 비평으로 기여하는 모든 사람을 환영합니다. 언어, 경험 수준, 정체성, 능력에 관계없이 프로젝트 공간이 유용하고 안전하기를 바랍니다.

<a id="how-we-work-together"></a>

## 함께 일하는 방식

- 작업, 근거, 영향에 관해 토론하세요. 제안한 사람을 공격하지 말고 아이디어를 검토하세요.
- 사용하는 언어나 기술 배경이 다를 때 명확하고 인내심 있게 소통하세요. 모욕하지 않고 오류를 바로잡으며 선의의 지적을 받아들이세요.
- 관련 있는 피드백을 주고 다른 사람도 참여할 수 있게 하세요.
- 비공개 정보를 보호하세요. 로그와 스크린샷을 가리고, 인증 정보나 다른 사람의 신원·계정 데이터를 노출하지 마세요.

괴롭힘, 차별, 위협, 스토킹, 성적인 관심, 고의적인 위압, 신상 공개, 인증 정보 공개, 지속적인 방해, 스팸을 허용하지 않습니다.

<a id="scope-and-enforcement"></a>

## 적용 범위와 조치

이 정책은 저장소 이슈, 풀 리퀘스트, 리뷰, 릴리스와 누군가 qhud 프로젝트를 대표하는 기타 공간에 적용됩니다.

일반적인 문제는 유해하거나 비공개인 내용을 반복하지 말고 같은 대화에서 수정을 요청하세요. 비공개 또는 긴급 신고에는 GitHub의 차단·신고 도구를 사용하세요. 민감한 개인정보를 공개 이슈에 적지 마세요.

관리자는 행동의 심각도와 반복 여부에 따라 내용을 수정·삭제하거나, 경고하거나, 참여를 제한하거나, 계정을 차단할 수 있습니다. 신고 내용은 검토에 필요한 사람에게만 공유합니다. 신고에 연관된 관리자는 다른 검토자가 있다면 결정에서 빠져야 합니다.
