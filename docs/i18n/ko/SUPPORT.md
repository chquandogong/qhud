# 지원

qhud는 커뮤니티가 관리하는 프로젝트입니다. English, 한국어, 简体中文으로 가능한 범위에서 지원합니다.

<a id="before-asking"></a>

## 문의하기 전에

[사용자 가이드](docs/GUIDE.md), [운영 지침서](docs/05-ops/RUNBOOK.md)의 플랫폼 안내, [기존 이슈](https://github.com/chquandogong/qhud/issues)를 먼저 확인하세요. 가능하면 최신 릴리스를 사용하고, 버전을 적을 때는 정확한 릴리스(예: `vX.Y.Z`) 또는 커밋 SHA를 입력하세요.

<a id="choose-the-right-channel"></a>

## 알맞은 경로 선택

- 재현할 수 있는 qhud 오류는 [버그 신고 양식](https://github.com/chquandogong/qhud/issues/new?template=bug_report.yml)을 사용하세요.
- 새로운 동작이나 사용 사례는 [기능 제안 양식](https://github.com/chquandogong/qhud/issues/new?template=feature_request.yml)을 사용하세요.
- 설치, 설정 또는 문서의 동작이 명확하지 않으면 [지원 질문 양식](https://github.com/chquandogong/qhud/issues/new?template=support_question.yml)을 사용하세요.
- 의심되는 취약점은 [SECURITY.md](SECURITY.md)의 안내에 따라 비공개로 신고하세요.
- 제공자 계정 접근, 구독, 결제, 서비스 상태 또는 제공자 측 인증 오류는 해당 AI 제공자에게 문의하세요.

운영체제와 데스크톱, 설치 방법, qhud 버전, 제공자 또는 구성요소, 시도한 방법과 정확한 결과를 포함하세요. 관리자는 이전 버전을 조사하기 전에 최신 릴리스에서도 문제가 발생하는지 확인해 달라고 요청할 수 있습니다.

<a id="protect-private-data"></a>

## 비공개 데이터 보호

진단 자료와 스크린샷에는 이메일 주소, 계정 또는 조직 ID, 로컬 경로, 세션 내용, 토큰, 인증 정보가 포함될 수 있습니다. 게시하기 전에 직접 확인하고 가리세요. `auth.json`, `.credentials.json`, 제공자 설정 디렉터리 또는 검토하지 않은 전체 진단 묶음을 첨부하지 마세요. 가능하면 작은 합성 예시를 사용하세요.
