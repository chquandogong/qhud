qhud v0.7.3 gives Codex plan badges the current product names and packages the
security, dependency, release, and translation work completed after v0.7.2.

- **Current Codex plan names.** The reviewed wire values `prolite`, `pro`, and
  `promax` now display as **Pro 100**, **Pro 200**, and **Pro 500**. The mapping
  follows Codex's upstream [wire enum](https://github.com/openai/codex/blob/f70810bcd210ed780a3da5940e9e60f74ac8ee60/codex-rs/protocol/src/auth.rs#L73-L95),
  [subscription labels](https://github.com/openai/codex/blob/f70810bcd210ed780a3da5940e9e60f74ac8ee60/codex-rs/tui/src/subscription.rs#L10-L19),
  and [regression cases](https://github.com/openai/codex/blob/f70810bcd210ed780a3da5940e9e60f74ac8ee60/codex-rs/tui/src/status/helpers.rs#L200-L221).
  An explicit `accounts.json` plan label remains the highest-priority display
  override. Unknown provider values stay available in detail text but do not
  become a user-facing badge.
- **Security gates and redacted errors.** A cargo-deny job now checks the locked
  Rust graph for advisories, licenses, and sources. The graph includes rustls
  0.23.45 for RUSTSEC-2026-0285. Remaining ambient library failures use bounded,
  typed categories instead of copying upstream text that can contain a URL,
  path, or terminal-multiplexer output.
- **Gated release assets.** Releases now include a CycloneDX 1.5 JSON SBOM with
  a SHA-256 sidecar and provenance attestation. The publication job reliably
  resumes its draft by listing releases, verifies exactly six assets, and
  refuses mismatched or unexpected files. `codex/**` work runs CI once through
  its pull request rather than once for both the branch push and the PR.
- **Dependencies and translations.** base64 0.23, libloading 0.9, reqwest
  0.13.5, and toml 1.1.6 are included. The repository now defines which English
  documents require complete Korean and Simplified Chinese mirrors and checks
  their facts and change coverage in CI.

Automated JavaScript regression tests cover the three exact plan mappings,
case and surrounding-whitespace normalization, explicit-override precedence,
and suppression of unknown wire values. No live desktop plan-badge pass had
been performed before publication. On 2026-10-01, a post-publication native
Windows pass verified the published ZIP at SHA-256
`d6268bfd696e2a9c8b17d77a6590bfb11df18d73498e9d96f627998114183d4f`,
raw `pro` rendering as **Pro 200**, executable and About version 0.7.3, and
CPU, memory, GPU, disk and network rendering. A private local screenshot was
inspected and then deleted; the dated record is in
[`TEST_PLAN.md`](../../04-quality/TEST_PLAN.md).
