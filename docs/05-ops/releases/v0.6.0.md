qhud v0.6.0 adds a native Windows x64 widget while retaining the Linux x86_64 release.

- **Windows:** extract `qhud-v0.6.0-windows-x86_64.zip` and run `qhud.exe`.
  Microsoft Edge WebView2 Runtime is required. Account usage works without WSL;
  native Windows Terminal/PowerShell pane discovery is not implemented.
- **Linux:** install the `qhud-v0.6.0-linux-x86_64.tar.gz` binary as before.
  GTK/X11 and tmux/herdr code paths remain in place, and source builds continue
  using the pinned Git dependency without a local dependency checkout.
- **Model limits:** preserve model-only readings and each window's reset,
  handle nullable Codex limit maps, and fix the current Codex app-server fallback.
  Long model labels wrap; the usage strip scrolls; hover a gauge for the exact
  reset time. A model is shown only if the provider returns its limit.
- **Account correctness:** match saved usage to the signed-in account and keep
  simultaneous provider refreshes from overwriting one another.

Upgrade notes: without a multiplexer, qhud now displays real local account
snapshots with zero panes; use `--demo` for example data. Provider/config home
environment overrides are honored. Old Antigravity snapshots without an account
identity need one explicit refresh. No credentials or user account settings are
included in the release.

Validation: Ubuntu 24.04 passed fmt/clippy, 98 tests and the release build;
Windows passed 98 tests and the release build. The installed Windows binary
also passed a display and account-refresh smoke check. Ubuntu desktop
integration was not manually re-tested during this Windows port.

Both platform build/test jobs must pass before this release is published.
SHA-256 checksum files accompany the downloads.
