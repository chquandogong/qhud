qhud v0.8.0 brings account connection status, reset credits and a plan-specific model guide to the usage panel.

- Windows connects to the installed Codex CLI and the running Antigravity app. Codex, Claude and Antigravity show local readiness, credential expiry when available, the last refresh result and the age of saved usage. `qhud --provider-health` reads local status. `qhud --refresh-health` explicitly fetches usage.
- Register personal and team profiles for Codex and Claude in `accounts.json`. `scripts/Connect-Account.ps1` opens the provider’s login for an isolated profile. A profile awaiting sign-in stays visible without quota values. Codex keeps each login’s usage separate even when two people share a workspace.
- Reset credits show the remaining count returned by the provider, including zero. Claude shows personal Ultra or Max 5x and identifies a team member’s usage grade separately from their organization plan. Antigravity shows the native plan name, such as Google AI Pro, alongside the account’s snapshot.
- Open **Supported models** beside a recognized plan or seat for a guide dated 2026-11-23. It describes model availability and conditions such as paid subscriptions versus trials, team seat type and credit requirements. The provider’s model picker reflects the account’s current permissions. A manually verified Codex team seat shows its source and verification date.

During development on 2026-11-23, the native Windows widget showed the model guide for a saved Standard seat while its Codex profile still required sign-in. Live quota retrieval for that profile remains unverified.
