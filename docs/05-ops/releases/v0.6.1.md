qhud v0.6.1 is a documentation and verification release. The binaries behave
exactly as v0.6.0 — the only source edits are stale comments — so upgrading
is optional for anyone already running v0.6.0.

- **Specifications rewritten from scratch.** `docs/03-spec/SPEC.md` and
  `docs/03-spec/ARCHITECTURE.md` were rebuilt against the v0.6.0 source rather
  than patched. The previous SPEC stopped at v0.5.0 and the previous
  ARCHITECTURE was a v0.4.0 document: between them they omitted four modules,
  both platforms' path handling, the frame guard, the dual-platform release, and
  every CLI flag and environment variable added since. Requirements now cover
  every shipped release, each carrying the decision that produced it.
- **Ubuntu verification recorded.** v0.6.0 shipped from a Windows host and noted
  that Ubuntu desktop integration had not been re-exercised. It has been now, on
  the published v0.6.0 Linux asset: checksum verified, installed, and confirmed
  on the reference machine down to the desktop-layer window states, pixel
  liveness, multiplexer observation and all three provider refreshes. The dated
  evidence is in `docs/04-quality/TEST_PLAN.md` and `docs/00-overview/DASHBOARD.md`.
- **Risks and assumptions refreshed.** The register now carries the
  display-sleep frame freeze that dominates field events, provider wire-format
  drift, and the Windows-specific limits; stale single-platform and
  never-persists assumptions are corrected.
- **Field numbers corrected.** The frame guard's journal-captured tally is 28
  freezes and 28 remap heals with zero re-execs and zero operator-visible
  incidents (2026-08-26 → 09-07). Earlier releases quoted a much smaller count
  taken from the guard's first days.

No credentials, account settings, or operator display names are included in the
release. Both platform build and test jobs must pass before publication, and
SHA-256 checksum files accompany both downloads.
