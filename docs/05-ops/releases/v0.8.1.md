qhud v0.8.1 groups usage by email within each provider. Read the personal row first, then each team’s row to compare their plans, usage windows and reset times. Profiles awaiting a connection appear under the same email.

A Claude personal profile with a web-confirmed **Free** plan and no returned quota shows **Usage unavailable** without a gauge. Its plan details include the verification time. A matching provider usage row takes precedence. A team under the same email keeps its own quota.

On 2026-11-23, a local Windows build showed Codex personal and team rows together. In Claude, the personal Free row showed **Usage unavailable** beside the same email’s paid team usage. To update on Windows, quit qhud from the tray, replace the executable with the copy from the release ZIP, and relaunch using the same Windows account.
