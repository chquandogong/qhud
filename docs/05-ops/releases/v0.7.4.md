qhud v0.7.4 fixes an overlap in the narrow system strip and moves the dependency
stack forward.

- **Narrow system strip.** In a narrow window the disk rates were drawn over the
  network label: WebKitGTK renders the strip's small mono text larger than a
  browser does, so a half-row rate cell overflowed. Below 320 CSS pixels each
  rate now takes its own row, and a value that still does not fit is clipped
  inside its own cell. Wider windows keep the shared row.
- **Tauri 2.12.1.** Tauri moves from 2.11 to 2.12.1, with tauri-build 2.7.1 and
  the window-state, opener and single-instance plugins. `sysinfo` moves to
  0.38.4. Tauri 2.12 drops `urlpattern` 0.3, so five unmaintained-crate
  exceptions leave the dependency policy.
- **Rust 1.90 for source builds.** The declared minimum moves from 1.88 to 1.90,
  which Tauri 2.12 requires. The locked graph had already needed 1.89, so 1.88
  was no longer accurate; a new CI job now builds on the declared version.
- **Repository.** `Rust dependency policy` is now a required check on `main`,
  and the README shows native Linux captures in demo mode (compact, expanded and
  About) instead of browser renders.

Verified on Ubuntu 24.04 with the native release build under Xvfb in demo mode:
the strip was checked at 300, 360, 450 and 600-pixel windows, the main window,
tray, expanded tile and About dialog rendered, and frames kept repainting. The
Tauri 2.12 build was not run in a live GNOME session or on Windows hardware
before publication; Windows CI tests and builds remain the gate.

Post-publication on 2026-10-02, the published Windows ZIP matched SHA-256
`d1c5bcbd7177075fcf00d48cd1d9a2239f8415f97b3ec945eaeeaa59a3a098cf`,
and its executable and About dialog reported v0.7.4. The native WebView2 build
ran in isolated `--demo` mode with synthetic values, fresh, isolated provider
and configuration homes, and a fresh 100% zoom profile. At default zoom the
CPU/MEM/GPU/DISK/NET strip did not overlap at the checked 394-pixel normal and
361-pixel narrow window widths. Windows Graphics Capture retained 394×522
compact, expanded, and About images; About displayed the homepage and GitHub
links. No live account was used, and link activation and the remaining Windows
interaction checklist were not exercised in this pass.
