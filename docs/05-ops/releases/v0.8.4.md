## Reconnect an account on Windows

Select **Sign in again** on the expired personal or team row. If an isolated profile is signed in to another account, select **Sign in to this account**. Claude pre-fills the email and preselects the organization when its ID is known. Codex first tries its saved session and restricts a new login to the known workspace. If the browser offers another account, switch to the email shown on the row.

qhud checks the new login in a separate profile before updating the existing connection. Cancelling or selecting a different email or workspace preserves the original login. After verification, qhud requests usage and reports whether the selected account returned fresh data.

## Claude limit resets

When the usage response omits the remaining count, qhud can show the most recent observation recorded from **Settings → Usage → Limit resets** for the matching member and organization. Expand the badge for the number and expiry of each reset type and the time it was checked. Expired offers drop out of the total. A provider count takes priority, including zero.

On Windows, quit qhud from the tray, extract the release ZIP and relaunch under the same Windows account. The existing account registry is reused.
